# Experimento A/B en landing page

Proyecto del bootcamp de Análisis de Datos de TripleTen (Sprint 9). Validación de hipótesis de negocio mediante pruebas estadísticas.

## Objetivo

Evaluar, con rigor estadístico, un experimento A/B realizado sobre una página de inicio (landing page) con dos versiones (A y B), para apoyar una decisión de negocio basada en datos sobre cuál versión conviene mantener.

## Qué se hizo

- **Carga y validación de datos**: revisión del dataset de usuarios expuestos a las versiones A y B del experimento.
- **Planteamiento de hipótesis**: definición formal de hipótesis nula y alternativa sobre la métrica de negocio relevante (conversión).
- **Prueba estadística**: aplicación de una prueba de hipótesis (test de proporciones/Chi-cuadrado) con un nivel de significancia definido (alpha = 0.05) para determinar si la diferencia observada entre grupos es estadísticamente significativa.
- **Interpretación de resultados**: conclusión sobre si se rechaza o no la hipótesis nula, y qué implica para la decisión de negocio.

## Herramientas

Python — pandas, scipy.stats (pruebas de hipótesis), Jupyter Notebook.
